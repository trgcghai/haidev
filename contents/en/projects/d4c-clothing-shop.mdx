# D4C Clothing Shop

## Overview

An eCommerce system developed using a microservices architecture to learn and apply distributed systems development knowledge. This project is solely intended to apply the knowledge that has been learned.

## Features

- Product management
- User management
- Cart & payment
- Recommendation algorithm based on product interaction scoring
- Product search and shopping, order management

## Stack

- Frontend: React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, Radix UI, Zustand, TanStack Query.
- API Gateway: Spring Cloud Gateway.
- Service Registry: Spring Boot Eureka Discovery Server.
- Services: Spring Boot, ExpressJS
- Database & Caching: MariaDB, Redis, AWS DynamoDB, AWS S3.
- Messaging: RabbitMQ.
- Product Search: Typesense.
- Monitoring: Elasticsearch, Kibana, Logstash.
- Docker and Docker Compose for packaging.

## Architecture

The application is organized as a monorepo for a microservices architecture.

Core application services include:

- `UserService`: authentication and user management.
- `ProductService`: product, category, variant, and media-related APIs.
- `CartService`: shopping cart operations with Redis support.
- `OrderService`: order lifecycle management.
- `PaymentService`: payment processing integration.
- `NotificationService`: notification handling with RabbitMQ.
- `RecommendationService`: product recommendation APIs that based on user behavior algorithm.
- `AIService`: AI chatbot features.
- `SearchService`: search indexing and query support.

Infrastructure services include MariaDB, Redis, RabbitMQ, Elasticsearch, Kibana, Logstash and Typesense.
