# Manga Reader

## Overview

A FOSS for reading and managing your manga / comic library. Self-hosted, everything stays on your computer. The main features includes reading, manga / comic management, reading progress, tracking manga progress based from 3rd sources such as other manga sites.

## Stack

The project uses a TypeScript-based full-stack architecture.

- `Backend`: NestJS
- `Frontend`: React, TanStack, ShadcnUI, TailwindCSS
- `Storage`: MinIO
- `Database & Caching`: PostgreSQL, Redis
- `Packaging`: Docker Compose

## How to Run

The recommended way to run the project is with Docker Compose from the repository root:

```bash
git clone https://github.com/trgcghai/Manga-Reader.git
```

```bash
docker compose up -d --build
```

Below are the default ports of the compose, you can modify as you want if it conflicts with your existed ports. If you already have your MinIO, feel free to use it and shut the MinIO of the compose off.

Common local URLs:

| Service       | URL                     |
| ------------- | ----------------------- |
| Frontend      | `http://localhost:3000` |
| Backend       | `http://localhost:3001` |
| MinIO Console | `http://localhost:9001` |

You can also run each app manually.

Backend:

```bash
cd backend
npm install
npm run start:dev
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```
