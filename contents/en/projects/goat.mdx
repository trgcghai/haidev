## Overview

A platform for job seeking and hiring based on networking. Main features includes messaging, connecting, hiring and CMS for content sharing.

## Features

- Networking via friendship, direct or group messaging, video and audio call.
- Job management, application management.
- Profile, CV and interview calendar management, company rating.
- Sharing contents on the CMS, interacting with others (commment, reaction, share post).
- Job seeking, applying and messaging more easier with AI chatbot.

## Stack

- Backend: Java 21, Spring Boot, Spring Security, WebSocket, Mail, OpenAPI, Liquibase, Redis, PostgreSQL, AWS S3, Agora webRTC.
- Web frontend: Next.js, React, TypeScript, TailwindCSS, Redux Toolkit,React Hook Form, Zod, Axios, STOMP/SockJS, Agora RTC Web SDK, Recharts, Framer Motion.
- Mobile frontend: Expo, React Native, Expo Router, TypeScript, Redux Toolkit, React Hook Form, Zod, Axios, STOMP/SockJS, React Native Agora, React Native Paper, Reanimated, Gesture Handler.
