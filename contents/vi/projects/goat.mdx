## Tổng quan

Là nền tảng hỗ trợ tìm kiếm việc làm và tuyển dụng dựa trên nguyên lý networking. Tính năng chính xoay quanh nhắn tin, kết nối, tuyển dụng và nền tảng CMS để chia sẻ nội dung.

## Tính năng

- Kết bạn, nhắn tin, trò chuyện trực tuyến 1-1 hoặc theo nhóm, gọi điện audio và video.
- Quản lý tin tuyển dụng, ứng tuyển công việc.
- Quản lý hồ sơ việc làm, CV, lịch phỏng vấn, đánh giá công ty.
- Đăng tải nội dung lên CMS, tương tác với nhau trong CMS (commment, reaction, share).
- AI chatbot hỗ trợ trong quá trình tìm việc, ứng tuyển, nhắn tin.

## Công nghệ (Stack)

- Backend: Java 21, Spring Boot, Spring Security, WebSocket, Mail, OpenAPI, Liquibase, Redis, PostgreSQL, AWS S3, Agora webRTC.
- Web frontend: Next.js, React, TypeScript, TailwindCSS, Redux Toolkit,React Hook Form, Zod, Axios, STOMP/SockJS, Agora RTC Web SDK, Recharts, Framer Motion.
- Mobile frontend: Expo, React Native, Expo Router, TypeScript, Redux Toolkit, React Hook Form, Zod, Axios, STOMP/SockJS, React Native Agora, React Native Paper, Reanimated, Gesture Handler.
