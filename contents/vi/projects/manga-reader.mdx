# Manga Reader

## Tổng quan

Là 1 FOSS để đọc manga và quản lý thư viện của bản thân. Mô hình self-host, mọi dữ liệu nằm trên máy của bạn. Các tính năng chính bao gồm đọc truyện, quản lý thư viện, tiến trình đọc, theo dõi tiến độ bộ truyện dựa vào các manga sites khác.

## Công nghệ sử dụng

Dự án sử dụng kiến ​​trúc full-stack dựa trên TypeScript.

- `Backend`: NestJS
- `Frontend`: React, TanStack, ShadcnUI, TailwindCSS
- `Storage`: MinIO
- `Database & Caching`: PostgreSQL, Redis
- `Packaging`: Docker compose

## Cách sử dụng

Cách được khuyến nghị là dùng Docker Compose từ thư mục gốc:

```bash
git clone https://github.com/trgcghai/Manga-Reader.git
```

```bash
docker compose up -d --build
```

Bên dưới là các port mặc định của docker compose, bạn có thể tùy chỉnh port nếu nó trùng với port bạn đang sử dụng. Nếu bạn đã có sẵn MinIO, có thể sử dụng MinIO của bạn và tắt MinIO trong compose đi.

| Dịch vụ       | URL                     |
| ------------- | ----------------------- |
| Frontend      | `http://localhost:3000` |
| Backend       | `http://localhost:3001` |
| MinIO Console | `http://localhost:9001` |

Bạn cũng có thể chạy thủ công từng ứng dụng.

Backend:

```bash
cd backend
npm install
npm run start:dev
```

Frontend:

```bash
cd frontend
npm install
npm run dev
```
