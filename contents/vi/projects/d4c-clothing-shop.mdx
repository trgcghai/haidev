# D4C Clothing Shop

## Tổng quan

Là hệ thống eCommerce được thực hiện với kiến trúc microservices để học hỏi và áp dụng kiến thức phát triển hệ thống phân tán. Dự án này chỉ để áp dụng kiến thức đã học.

## Các tính năng

- QUản lý sản phẩm
- Quản lý người dùng
- Giỏ hàng & thanh toán
- Thuật toán gợi ý bằng cách tính điểm tương tác sản phẩm
- Tìm kiếm và mua sắm, quản lý đơn hàng

## Công nghệ sử dụng

- Frontend: React 19, TypeScript, Vite, Tailwind CSS, shadcn/ui, Radix UI, Zustand, TanStack Query.
- API Gateway: Spring Cloud Gateway.
- Service Registry: Spring Boot Eureka Discovery Server.
- Các services con: Spring Boot, ExpressJS
- Database & Caching: MariaDB, Redis, AWS DynamoDB, AWS S3.
- Messaging: RabbitMQ.
- Tìm kiếm sản phẩm: Typesense.
- Monitor: Elasticsearch, Kibana, Logstash.
- Docker và Docker Compose để đóng gói.

## Kiến trúc

Ứng dụng được tổ chức theo mô hình monorepo cho kiến ​​trúc microservices.

Các dịch vụ cốt lõi của ứng dụng bao gồm:

- `UserService`: xác thực và quản lý người dùng.
- `ProductService`: các API liên quan đến sản phẩm, danh mục.
- `CartService`: các thao tác với giỏ hàng, caching vào Redis.
- `OrderService`: quản lý vòng đời đơn hàng.
- `PaymentService`: tích hợp xử lý thanh toán.
- `NotificationService`: xử lý thông báo với RabbitMQ.
- `RecommendationService`: các API gợi ý sản phẩm dựa thuật toán gợi ý dựa vào hành vi người dùng.
- `AIService`: chat với AI chatbot.
- `SearchService`: lập index tìm kiếm sản phẩm.

Các dịch vụ hạ tầng bao gồm MariaDB, Redis, RabbitMQ, Elasticsearch, Kibana, Logstash và Typesense.
